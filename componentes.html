Modal

Una tarea o explicación que interrumpe el contexto.

Úsalo cuando
Una acción breve y necesaria, con cierre claro.
Evítalo cuando
Contenido extenso o navegación rutinaria.

Tabla

Datos comparables en filas y columnas.

Úsalo cuando
Precios, características o registros con encabezados.
Evítalo cuando
Maquetar una página o mostrar tarjetas sin relaciones tabulares.
Comportamiento
caption y th comunican relaciones; el desplazamiento puede ser interno.
Documentación del patrón
Lista

Colección de elementos relacionados.

Úsalo cuando
Pasos, recursos, tareas o resultados sencillos.
Evítalo cuando
Cuando los datos necesitan relaciones entre varias columnas.
Comportamiento
ol para secuencia; ul cuando el orden no es significativo.
