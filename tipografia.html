DISEÑO QUE PUEDES PROBAR

Seis familias para empezar.

Estas categorías son una guía práctica y se solapan: slab es una clase de serif, y display describe un uso. Mira formas, proporciones y legibilidad, no solo la etiqueta.

Cargando tipografías; si una no llega se muestra su alternativa.

SERIF · Lora

Aa

Sabor

Clásica, editorial, cálida.

Ideal como punto de partida: Restaurantes, lectura extensa, marcas con tradición.

Una serif robusta puede ser muy legible en pantalla; prueba tamaños pequeños y su contraste.

Ver familia y licencia

SERIF · Playfair Display

Aa

Sabor

Elegante, con contraste y voz editorial.

Ideal como punto de partida: Moda, portadas, títulos de marcas refinadas.

Sus detalles finos necesitan tamaño y contraste suficientes.

Ver familia y licencia

SANS-SERIF · Inter

Aa

Sabor

Neutral, funcional, centrada en interfaz.

Ideal como punto de partida: Apps, paneles, servicios y texto de pantalla.

Neutral no significa sin personalidad; peso y espaciado cambian su tono.

Ver familia y licencia

SANS-SERIF · Manrope

Aa

Sabor

Moderna, geométrica, abierta.

Ideal como punto de partida: Tecnología, educación, portafolios.

Una fuente geométrica debe probarse con párrafos reales, no solo logos.

Ver familia y licencia

SLAB SERIF · Roboto Slab

Aa

Sabor

Robusta, estable, con remates marcados.

Ideal como punto de partida: Titulares, blogs y marcas con presencia.

No asumas que todas las slab se comportan igual en cuerpo.

SLAB SERIF · Zilla Slab

Ideal como punto de partida: Publicaciones, cultura, marcas expresivas.

DISPLAY · Bebas Neue

DISPLAY · Abril Fatface

También puedes estudiar serif de estilo antiguo, transicionales y didonas; sans humanistas, grotescas y geométricas; fuentes variables y familias con muchos idiomas. Una fuente variable permite ajustar ejes como peso o ancho, pero solo los que la familia ofrece.

ETIQUETA / CONTEXTO

Una jerarquía que se entiende.

Un subtítulo ordena la lectura.

Un cuerpo legible necesita espacio entre líneas y una medida cómoda. No escales todos los textos del mismo modo: títulos, botones, tablas y notas tienen tareas distintas.

Nota secundaria, con tamaño legible.

Familias
Una o dos suelen bastar. Si usas más, asigna una función estable a cada una.
Pesos
Selecciona los necesarios; cargar muchos archivos aumenta el coste de la página.
Medida
Un ancho aproximado de 45–75 caracteres puede servir como punto de partida para párrafos; pruébalo con tu fuente y contenido.
Escala
Usa rem para tamaños base y clamp para titulares adaptables, sin impedir el zoom.

DISEÑO QUE PUEDES PROBAR

La prueba real está en el contenido.

“Aa” ayuda a ver formas; un párrafo, un precio y una dirección ayudan a decidir si sirven.

Idioma y cobertura

Prueba ñ, tildes, ¿?, ¡!, símbolos monetarios, números y nombres propios. Una alternativa puede cambiar la medida del texto.

Contexto de lectura

Compara móvil y escritorio, texto largo y controles. Prueba tamaño ampliado y conexión lenta.

Accesibilidad

No uses pesos excesivamente finos ni color tenue para información esencial. La elección debe facilitar la lectura.

Una receta que puedes copiar 
:root {
  --font-body: "Inter", system-ui, sans-serif;
  --font-heading: "Lora", Georgia, serif;
}
body { font-family: var(--font-body); font-size: 1rem; line-height: 1.6; }
h1, h2, h3 { font-family: var(--font-heading); line-height: 1.15; }
h1 { font-size: clamp(2rem, 5vw, 4rem); }
.texto { max-width: 65ch; }

Consulta Google Fonts Knowledge para profundizar en anatomía, clasificación y selección.
